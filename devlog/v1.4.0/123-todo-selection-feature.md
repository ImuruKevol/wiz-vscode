# 123. TODO 목록 선택 시작 기능 (v1.4.0)

## 개요
TODO 목록에서 항목을 선택하여 부분적으로 작업을 실행할 수 있는 기능 추가.

## 변경 사항

### 1. 체크박스 선택 기능 (`src/editor/editors/todoViewerEditor.js`)
- ID 입력 필드 옆에 체크박스 추가
- 각 페이지 탐색 시 해당 항목의 선택 상태가 체크박스에 반영
- ID가 없는 항목은 체크박스 비활성화

### 2. 선택된 항목 해시태그 바
- 제목과 에디터 사이에 선택된 항목 표시 바 추가
- 해시태그(뱃지) 스타일로 선택된 ID 표시
- 각 태그에 × 버튼으로 선택 해제 가능
- 선택된 항목이 없으면 바 자동 숨김

### 3. 작업 시작 선택 실행
- 선택된 항목이 있으면 해당 ID만 Copilot Chat에 전달
- 확인 다이얼로그에 선택된 ID 목록 표시
- 선택 없으면 "전체 항목을 실행합니다" 확인 다이얼로그 표시
- `handleRunTask` 메서드가 선택된 ID 배열을 받도록 수정

### 4. 상태 관리
- 선택 상태(`selectedIds`)를 `vscode.setState`로 영속화
- 패널 복원 시 선택 상태 복원
- ID 변경 시 선택 상태 자동 동기화
- 항목 삭제/새로고침 시 유효하지 않은 선택 자동 정리
