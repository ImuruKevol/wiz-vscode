# 108. 마크다운 뷰어 다운로드 버튼 복원 확인 (v1.3.2)

## 개요
리뷰에서 보고된 "마크다운 뷰어 다운로드 버튼 사라짐" 이슈를 점검하고 현재 상태를 확인.

## 변경 사항

### 1. 현재 상태 확인
- `src/editor/editors/markdownViewerEditor.js`의 `_generateHtml()` 메서드에 `📥 PDF` 버튼이 정상적으로 존재
- 헤더 영역에 `btnPdf` (PDF 다운로드) + `btnEdit` (편집하기) 두 버튼이 배치됨
- html2pdf.js 외부 스크립트 로드 방식으로 PDF 생성 기능 정상 구현 상태

### 2. 원인 분석
- 커밋된 코드(v1.3.2 태그)에는 PDF 버튼 미포함 — devlog #106에서 추가, devlog #107에서 수정된 변경사항이 미커밋 상태
- 리뷰 시점에 패키지된 버전(v1.3.2)에서 버튼이 보이지 않았을 가능성
- 현재 워킹 트리에는 PDF 다운로드 버튼과 관련 로직이 모두 포함되어 있어 추가 코드 변경 불필요
