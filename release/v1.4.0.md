# Wiz VSCode Extension v1.4.0 Release Notes

> February 27, 2026

---

## Highlights

**v1.4.0** delivers **real-time editor file synchronization** using VS Code events, a major **MCP restructuring** (4 categories, 54 tools, modular codebase), **RichEditor improvements** for better editing UX, **non-WIZ project support** to work in any workspace, and **MCP state sync** for seamless project switching between VS Code and AI agents.

---

## New Features

### Editor Real-time File Synchronization
Webview editors now automatically reflect external file changes in real-time.

- **VS Code Event-based Sync**: Uses `onDidChangeTextDocument`, `onDidCreateFiles`, `onDidDeleteFiles` instead of raw `fs.watch` — more reliable across platforms
- **Debounced Refresh**: Prevents excessive updates with configurable delay
- **Infinite Loop Prevention**: Write-tracking strategy avoids circular save-refresh loops
- **Visibility-aware**: Only updates visible editors; deferred refresh on re-focus

### TODO Selection Feature
Enhanced TODO viewer with interactive selection capabilities.

- **Checkbox Selection**: Select individual TODO items via checkboxes
- **Hashtag Bar**: Quick-filter by tag categories
- **Batch Execution**: Run selected tasks as a group

### MCP Project State Sync
Bidirectional synchronization between VS Code Explorer and MCP server.

- **FileSystemWatcher**: Monitors `.vscode/.wiz-state.json` for external project switches
- **Auto UI Refresh**: When MCP switches project, Explorer/Info/Task views update automatically
- **Debounced**: 300ms debounce prevents rapid-fire updates

### Non-WIZ Project Support
Full workspace functionality even when opening non-WIZ (no `project/` folder) directories.

- **Task Management**: 작업 관리 and 인스트럭션 views remain fully functional
- **Info View**: Shows README (workspace root) + version info only
- **Explorer**: Displays "WIZ 구조의 프로젝트가 아닙니다" message without WIZ-specific items
- **Conditional UI**: Build, Switch Project buttons hidden via `wiz.isWizProject` context
- **Safe Defaults**: `isWizProject` defaults to `false`; initial context set before view creation

## Improvements

### MCP Restructuring (54 Tools, 4 Categories)
Complete reorganization of MCP tool architecture for better discoverability and AI agent usability.

- **4 Categories**: Workspace (7), Project (19), Source (13), Package (15)
- **Modular Codebase**: Split monolithic 1,673-line `index.js` into 7 files using prototype mixin pattern
  - `helpers.js`, `definitions.js`, `handlers/workspace.js`, `handlers/project.js`, `handlers/source.js`, `handlers/package.js`
- **New Tools**: `search_apps`, `list_layouts`, `list_controllers` and more

### RichEditor Improvements
Better editing experience in the WYSIWYG rich text editor.

- **List Depth Support**: Nested list indentation with proper bullet styles
- **Source Code View**: Toggle raw HTML source editing
- **Paste Cleanup**: Strip unnecessary formatting on paste (Selection/Range API)

### Copilot Chat Enhancements
- **Confirm Dialogs**: 6 confirmation modals before sending messages to Copilot Chat
- **Agent Mode**: All chat integrations open in agent mode for enhanced tool access
- **attachFiles API**: Reliable file context attachment replacing string interpolation

### View Action Buttons
- **Refresh Buttons**: Added to wizExplorer, wizTask, wizInstruction title bars
- **Task Instruction Improvement**: Enhanced prompt generation with detailed rules for TODO management
