# Wiz VSCode Extension v1.3.1 Release Notes

> February 23, 2026

---

## Highlights

**v1.3.1** introduces a dedicated **Copilot Explorer** view for AI-assisted development workflows, a **Task Management** system with wizard buttons for TODO creation, review cleanup, and task execution, and an **Instruction Wizard** that generates project instructions via Copilot Chat integration.

---

## New Features

### WIZ Copilot Explorer
A new independent Tree View dedicated to Copilot-related files and task management, separated from the main Source explorer.

- **Instruction Category**: Displays `.github` directory contents (excluding `task/`) with `book` icon
- **Task Management Category**: Displays `.github/task/` directory with `tasklist` icon
- **Lightweight Provider**: `CopilotExplorerProvider` shares state with main `FileExplorerProvider`
- **Auto-Sync**: Automatically refreshes when the main explorer updates
- **Full Context Menu**: Supports file create, delete, copy, paste, rename, download, upload operations

### Task Management Wizards
Three inline action buttons on the Task Management category for Copilot Chat integration:

| Button | Icon | Action |
|--------|------|--------|
| TODO 생성 마법사 | `$(add)` | Opens input dialog, sends "TODO 작성해줘" + user input to Copilot Chat |
| 리뷰 정리 마법사 | `$(wand)` | Sends "리뷰 정리해줘" to Copilot Chat |
| 작업 실행 | `$(play)` | Sends "작업 수행해줘" with `todo.md` file context to Copilot Chat |

### Instruction Generation Wizard
Inline button on the Instruction category that generates task-based work management instructions.

- **Copilot Chat Integration**: Sends structured prompt to Copilot Chat instead of direct file editing
- **Duplicate Prevention**: Checks for existing "Task 기반 작업 관리" content before generating
- **Smart Update**: AI analyzes existing `copilot-instructions.md` and merges instructions appropriately

## Improvements

### Explorer View Restructure
- **View Order**: Copilot view placed above Source view in the sidebar
- **Source View**: Renamed from "Files" to "Source" for clarity
- **Category Separation**: Copilot category removed from main FileExplorerProvider (moved to CopilotExplorerProvider)
- **Settings Rename**: "wiz settings" → "wiz info" with `info` icon

- New `src/explorer/copilotExplorerProvider.js` with `CopilotInstructionCategory` and `TaskCategory`
