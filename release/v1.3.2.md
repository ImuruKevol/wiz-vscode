# Wiz VSCode Extension v1.3.2 Release Notes

> February 25, 2026

---

## Highlights

**v1.3.2** delivers a comprehensive **TODO Viewer** with rich editing and pagination, a **Worked Review Editor** for task review workflows, a **Markdown Viewer** powered by remarkable + highlight.js, and a complete **Explorer Panel Redesign** splitting the sidebar into 4 independent views (Info, Task, Instruction, Explorer).

---

## New Features

### TODO Viewer & Editor
Full-featured Webview editor for `todo.md` with rich text authoring and task management.

- **Rich Text Editor**: WYSIWYG editing with image upload, Markdown conversion, and auto-formatting
- **Pagination**: Numeric page navigation for browsing multiple tasks
- **Task Actions**: Add, save, view markdown source, and start task execution
- **Singleton Pattern**: Single editor instance prevents duplicate panels
- **UI Layout**: Buttons moved to header bar, streamlined layout

### Worked Review Editor
Dedicated Webview editor for reviewing completed task files in the `worked/` directory.

- **Pagination**: Browse through worked files with page controls
- **Rich Text Editing**: Full RichEditor support for review notes
- **Action Buttons**: QuickPick integration for task actions (review cleanup, task execution)
- **Click-to-Open**: Clicking the worked folder in the tree opens the review editor directly

### Markdown Viewer
Server-side rendered Markdown preview using remarkable + highlight.js.

- **Syntax Highlighting**: Code blocks rendered with highlight.js themes
- **GitHub-Style**: Clean markdown rendering with proper styling
- **Instruction Preview**: Used for `.github` markdown file previews

### Explorer Panel Separation (4 Independent Views)
The sidebar is now split into 4 dedicated views for better organization.

| View | Content | Description |
|------|---------|-------------|
| **Wiz Info** | Settings, version, MCP config | Compact project info panel |
| **작업 관리** | `.github/task/` | Task management with download/upload |
| **인스트럭션** | `.github/` (excl. task) | Instructions with Git import/upload |
| **Explorer** | Source, Packages, Project | Main file explorer |

### Task & Instruction Download/Upload
- **Download**: Zip compression download for task and instruction folders
- **Upload**: Webview-based file upload for both task and instruction directories
- **Git Import Merge**: Clone to tmp folder, `cp -R` to `.github/` preserving existing files

## Bug Fixes

### MCP / Copilot Infinite Loop Fix
- Fixed `getParent` boundary guard causing infinite tree rebuilds
- Added auto-reveal guard and debounce to prevent memory exhaustion
- Resolved cascading refresh loops between MCP Configuration and Copilot Explorer

### RichEditor Auto-Format Fixes
- Switched from `keyup` to `keydown` for auto-format trigger to prevent duplicate conversions
- Fixed image insertion to use blob URLs instead of base64 data URIs

---

## Improvements

### RichEditor Component Extraction
- Extracted reusable `RichEditor` component from TODO editor into `resources/editor/richEditor.js`
- Shared across TODO Editor, TODO Viewer, and Worked Review Editor

### Instruction & Action Button UX
- Action buttons consolidated into QuickPick menus for cleaner UI
- Instruction confirmation dialog improved
- Git import icon changed from `$(cloud-download)` to `$(repo-clone)`
- Git clone logic changed to merge mode (clone to tmp → cp -R → preserve existing files)

### Multi-Select Delete
- File tree supports multi-select deletion with confirmation dialog
- Batch delete operation via `fileManager.deleteMultiple()`

### MCP Build Environment
- MCP server Python environment fallback improved
- Build command respects selected Python interpreter
