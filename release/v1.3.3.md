# Wiz VSCode Extension v1.3.3 Release Notes

> February 26, 2026

---

## Highlights

**v1.3.3** introduces the **Memo Feature** for quick note-taking with TODO integration, enhances **Copilot Chat** connectivity with Agent mode and the `attachFiles` API, and improves **Task Management** visibility when the task folder doesn't exist.

---

## New Features

### Memo Feature
Quick note-taking system integrated with the task management workflow.

- **Memo Viewer/Editor**: Rich WYSIWYG editor for `memo.md` with pagination for multiple notes
- **TODO Integration**: "TODO에 반영" button converts memo items to `todo.md` entries with auto-assigned `FN-` IDs
- **Viewer Transition**: After applying memos to TODO, memo viewer closes and TODO viewer opens automatically
- **Default Editor Button**: Open memos in VS Code's default text editor when needed

### Info View README
README file preview and creation directly from the Info panel.

- **Markdown Preview**: Renders project README with GitHub-flavored markdown styling
- **Create README**: Quick-create template when no README exists

---

## Improvements

### Copilot Chat Agent Mode
All Copilot Chat integrations now open in **Agent mode** for enhanced tool access.

- **`mode: 'agent'`**: Added to all 8 `workbench.action.chat.open` calls across 4 files
- **`attachFiles` API**: Task execution commands now use `attachFiles: [vscode.Uri.file(path)]` instead of `#file:` string interpolation for more reliable file context attachment
- **Affected commands**: Task run, review cleanup, TODO creation, instruction wizard, architecture analysis

### Task Management Menu Persistence
Task management tree items now appear even when `.github/task` folder doesn't exist.

- **Virtual Items**: "메모 (생성)" and "TODO (생성)" items shown with dimmed icons
- **Auto-create**: Clicking virtual items opens the viewer; first save auto-creates the directory

### Memo TODO Apply Fix
Resolved file save race conditions during memo-to-TODO transfer.

- **Direct Markdown Passing**: Webview markdown passed directly to `handleApplyToTodo()` instead of file I/O round-trip
- **Delayed Operations**: Added delays between todo.md save, memo.md clear, and viewer transitions (150ms/100ms/300ms)
- **Clear Verification**: Post-clear verification with retry if content remains

### Instruction View Action Buttons
Restructured instruction view action buttons with unified QuickPick menu for file/folder creation.

### Worked Folder File Count
Display `.md` file count badge on the "검토필요" (worked) folder item.

## Internal

### Explorer Panel Improvements
- Action button positioning adjusted (Explorer → Info view)
- Task view naming and ordering: 메모 → TODO → 검토필요 → 완료됨
- MCP README categorized into 8 categories with 36 tools

### Removed Features
- Markdown PDF download feature removed (html2pdf.js dependency cleaned up)
