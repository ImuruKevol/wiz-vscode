# Wiz VSCode Extension v1.4.1 Release Notes

> March 1, 2026

---

## Highlights

**v1.4.1** focuses on **MCP appPath resolution improvements** — fixing path resolution failures when AI agents use bare app names like `page.home`, enriching tool parameter descriptions with format examples, adding `appPath` relative path fields to list tool results, and updating the AI instruction document to match v3.0 tool naming. A comprehensive verification of all 54 MCP tools was performed.

---

## Bug Fixes

### MCP `_resolveAppPath` Path Resolution
The core path resolution function used by 20 MCP tools was rewritten to support multiple input formats.

- **Problem**: Bare app names (e.g., `page.agent`) resolved to `src/page.agent` instead of `src/app/page.agent`
- **Fix**: Implemented 10-step cascading path search:
  1. Absolute path → return as-is
  2. `src/` prefix → join with project root
  3. Direct path under project root
  4. `src/{appPath}` (relative under src)
  5. `src/app/{appPath}` (Source Apps)
  6. `src/route/{appPath}` (Source Routes)
  7. `{type}.{name}` pattern → `src/{type}/{appPath}`
  8. `src/portal/*/app/{appPath}` (Portal App glob)
  9. `src/portal/*/route/{appPath}` (Portal Route glob)
  10. Fallback: `src/{appPath}`
- **Impact**: All 20 appPath-using tools automatically benefit

## Improvements

### MCP appPath Parameter Descriptions
All 16 `appPath` parameter descriptions in tool definitions now include supported format examples.

- **Source tools** (8): `"page.home"`, `"app/page.home"`, `"src/app/page.home"`, `"route/my-api"`
- **Package tools** (8): `"login"`, `"portal/season/app/login"`, `"src/portal/season/app/login"`

### MCP List Tools — `appPath` Field in Results
App listing tools now return a relative `appPath` field that can be directly used with other tools.

- `_scanApps()` helper enhanced with optional `srcPath` parameter
- `wiz_source_list_apps`, `wiz_package_list_apps`, `wiz_project_search_apps` all return `appPath` field
- Example: `{ name: "page.agent", appPath: "app/page.agent", path: "/abs/..." }`

### MCP Instruction Document Tool Names
Updated `wiz-copilot-instructions/instructions.md` to match v3.0 tool naming convention.

- ~30 tool name references corrected (e.g., `wiz_create_app` → `wiz_source_create_app`)
- Section 3.1–3.5 tables reorganized to reflect 4-category structure
